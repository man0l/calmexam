# CalmExam

"The exam coach that's never wrong." A calm, exam-focused math practice app for **SAT Math**, **AP Calculus AB** and **A-Level Maths**, built with Expo (iOS, Android and web). Problems come from an on-device generator (`src/engine/`) whose answers are verified, so the app can say "Verified answer" plainly.

## Run locally

```bash
npm install
cp .env.example .env        # optional, defaults work
npm run web                 # or: npm start, then press i / a
```

`npm run ios` / `npm run android` build a dev client (`expo run:*`). RevenueCat needs a dev client; Expo Go works for everything else.

## Environment variables

| Name | Purpose |
|---|---|
| `EXPO_PUBLIC_API_BASE_URL` | Worker API base (default `https://calmexam.manol-trendafilov.workers.dev/api`). Used for `POST /explain`. |
| `EXPO_PUBLIC_REVENUECAT_KEY` | RevenueCat Play Store key (also iOS fallback). |
| `EXPO_PUBLIC_REVENUECAT_IOS_KEY` | RevenueCat App Store key. |
| `EXPO_PUBLIC_REVENUECAT_TEST_STORE_KEY` | RevenueCat Test Store key, `__DEV__` builds only. |

With no RevenueCat key, dev builds and web use a local billing stub so the paywall flow still works. Release builds without a key show "plans unavailable" instead of unlocking Pro. Entitlement id: `CalmExam Pro`; packages `ANNUAL` ($49.99) and `MONTHLY` ($7.99), 7-day trial.

## Scripts

| Script | What it does |
|---|---|
| `npm start` / `ios` / `android` / `web` | Expo dev server / native run / web |
| `npm run lint` | `expo lint` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run verify:engine` | Generates every template x 3000 seeds and checks the answers |
| `npm run export:web` | Static web build into `dist/` (gitignored) |

Assets in `assets/` are generated by `npx tsx scripts/generate-assets.ts` (pure JS PNG encoder).

## Web demo states (for screenshots)

Web only, ignored on native. Open `/?demo=<id>`. Each id resets local storage to a fixed state with a fixed seed, so the content is identical every run. Once the screen has rendered, the app root gets `data-testid="screen-ready"`.

| id | Screen |
|---|---|
| `onboarding` | Onboarding from the welcome screen |
| `exam` | Exam picker, SAT selected |
| `placement` | Placement question 2 of 5, nothing chosen |
| `plan` | Projection graph (with CalmExam vs on your own), SAT, 42 days left |
| `1` / `today` | Today tab: 42 days left, 5-day streak, goal ring 6/10 |
| `practice` / `progress` / `settings` | That tab with demo progress |
| `answer` | Practice session after a wrong answer: verified answer, steps, pitfalls |
| `explain` | Same problem with a canned "Explain my mistake" card (no network) |
| `paywall` | Paywall over Today |

Example: `npx expo export --platform web && npx serve dist`, then open `http://localhost:3000/?demo=answer`.

## Layout

```
App.tsx, index.ts        entry, providers, demo wiring
src/engine/              problem generator (shared with the Worker; do not edit here casually)
src/theme/               design tokens from docs/DESIGN.md
src/components/          UI building blocks (Button, Card, OptionButton, GoalRing, ProjectionGraph, ...)
src/screens/             Today, Practice, PracticeSession, Progress, Settings, EditPlan, Paywall
src/screens/onboarding/  welcome, exam, date, minutes, worries, placement, projection, plan
src/navigation/          root stack + bottom tabs
src/store/               Context stores persisted with AsyncStorage (profile, progress, subscription)
src/services/            api, purchases(.web), dates, streak, practice, review, haptics(.web), demo(.web)
src/hooks/, src/types/
scripts/                 verify-engine.ts, generate-assets.ts
docs/                    DESIGN.md, API.md
web/                     Cloudflare Worker (website + API), owned and built separately
```
